# Ministères — gabarit commun (v2)

Un seul site rend les 40 institutions à partir de `commun.jsx` (MINISTERES : noms FR/EN, catégorie, image contextuelle) et `app.jsx` (FICHES : missions FR/EN, 3 démarches phares avec service, coût, délai). Route `#<id>/<accueil|demarches|ministere>`, ex. `#minsante/demarches`. Les ministères disposant d'un site dédié (Présidence, Finances → Trésor, Arts et Culture → Musée, Sports, Tourisme) y renvoient.

Écrans : Accueil (hero contextuel, démarches phares, missions intérieur/extérieur, communiqués, où se rendre) · Démarches & services (coût, délai, service, paiement au Trésor) · Le ministère (organisation, textes, contact, ministères voisins).
