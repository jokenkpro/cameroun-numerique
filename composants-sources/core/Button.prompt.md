Primary action control; one primary per view, secondary for alternatives, tertiary for low-emphasis links, danger for destructive, inverse (yellow) on dark/green surfaces.
```jsx
<Button iconRight="arrow-right">Commencer la démarche</Button>
<Button variant="secondary">Enregistrer le brouillon</Button>
<Button variant="tertiary" iconLeft="download" size="sm">Télécharger</Button>
```
Sizes sm 32 / md 40 / lg 48px. Square corners; never add border-radius.
